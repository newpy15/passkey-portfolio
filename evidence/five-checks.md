# 5대 검사 기록 (8번 과제에서 비공개 영역을 붙인 소개 페이지)

- 대상: https://passkey-portfolio-6o03.onrender.com/
- 검사일: 2026-11-11
- 방법: 배포된 페이지를 앱 내장 브라우저로 열어 스크립트로 측정하고, 실제 Tab 키 입력으로 포커스 이동을 확인했습니다. 본인 PC 크롬에서 직접 찍은 캡처로 보강하는 것을 권합니다.

| 검사 | 방법 | 결과 |
|---|---|---|
| ① 링크 | `mailto:` 형식 확인, GitHub 프로필 링크 요청, 외부 링크 `rel="noopener noreferrer"` 확인 | 통과 — GitHub `200`, 이메일 형식 정상, 새 창 링크에 `noopener noreferrer` |
| ② Tab 이동 | Tab 키를 6번 눌러 포커스 순서와 포커스 테두리 확인 | 통과 — 이메일 → GitHub → **패스키로 열기** → 상세 근거 보기 ×3. 모든 요소에 2~3px 파란 테두리. `tabindex` 양수 사용 0건 |
| ③ 제목 순서 | `h1`~`h6` 순서 추출 | 통과 — `h1`(김도연) → `h2`(나의 강점) → `h3` ×3 → `h2`(비공개 영역 대화상자). 단계 건너뜀 0건 |
| ④ 명암비 | 화면의 글자 57개(대화상자 포함)의 글자색·배경색(그라디언트는 가장 불리한 색)으로 WCAG 계산, 기준 4.5:1 | 통과 — 실패 0건, 가장 낮은 값 **4.55:1**. 로그인 후에만 나타나는 색은 코드의 색 값으로 따로 계산해 7.29~17.85:1 |
| ⑤ 콘솔 오류 | 페이지 열기, 대화상자 열고 닫기 후 콘솔 확인 | 통과 — 로그 0건 |

## 알아 둘 점 (사실대로)

- **개발자 도구를 열어 둔 크롬**에서는 콘솔에 빨간 오류 2개가 보일 수 있습니다. `cdn.jsdelivr.net/…map`, `unpkg.com/…map`이 우리 보안 규칙(CSP `connect-src 'self'`)에 막힌 것으로, **개발자 도구가 소스맵 파일을 받으려다** 생기는 것입니다. 페이지 동작과는 무관합니다. 개발자 도구 설정(Sources → JavaScript source maps 끄기)에서 끄면 보이지 않습니다.
- 패스키 로그인 실패를 일부러 시도하면 콘솔에 `401`이 찍힙니다. 이는 서버가 올바르게 거절한 결과입니다.
- 소개 페이지는 외부 CDN(`unpkg.com`의 `lucide@latest`, `cdn.jsdelivr.net`의 Pretendard)을 불러옵니다. 1번 검사기록서의 "외부 의존성 없음"과 다릅니다.
- 이 검사는 로그아웃 상태의 화면 기준입니다. 로그인 후 화면의 명암비는 코드의 색 값으로 계산했습니다(성공 안내 7.29, 오류 안내 7.60, 삭제 버튼 8.31 등).
